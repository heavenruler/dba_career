## Summary

这篇文章讲的是 Java 生产环境 CPU 飙高时的排查思路：先用 top 找进程，再用 top -Hp 找线程，接着把线程 ID 转成 16 进制，最后用 jstack 定位到具体代码行。同时补充了权限不足和 GC 线程占满 CPU 的两个常见坑。
