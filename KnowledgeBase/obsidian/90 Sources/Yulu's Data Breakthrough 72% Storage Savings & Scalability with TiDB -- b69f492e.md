## Summary

Case study on migrating Yulu from monolithic RDS MySQL to a distributed TiDB cluster on AWS to address storage growth, write bottlenecks, DDL downtime, and availability risks. The migration used DM live replication, online schema changes, and TiKV storage efficiency to cut storage from 18TB to 3.4TB and improve scalability and resilience.
